# 📘 Online Math Test Platform

An interactive online platform for conducting **Math Mock Tests** with **Student** and **Admin** dashboards.  
This project is built using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

### 👨‍🎓 Student Dashboard
- Attend live mock tests.
- Submit answers and receive instant results.
- View detailed test performance.

### 👨‍💼 Admin Dashboard
- Create and manage tests.
- Track student performance.
- Analyze results with insights.

## ⚡ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/online-math-test-platform.git
   ```

2. Open `index.html` in your browser to start.
